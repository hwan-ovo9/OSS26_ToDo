# 프로젝트 소개 - Reminder

> Python 언어와 PyQt5 라이브러리로 제작된 ToDo(일정 관리)프로그램입니다.

마감 시간 관리, 중요도 분류, 카테고리 관리, 자동 저장, 메모 기능 등을 제공하며,
마감 시간이 가까워질수록 시각적으로 긴박감을 느낄 수 있도록 설계되었습니다.

---

## 주요 기능

### ✅ 할 일(Todo) 관리

- 할 일 추가
- 할 일 수정
- 할 일 삭제
- 완료 체크 기능
- 완료 항목 자동 분리
- 체크리스트 기능
- 개별 메모 기능

---

### 📋 체크리스트

각 Todo 내부에 세부 작업(Checklist) 작성 가능

- 체크 항목 추가
- 체크 항목 삭제
- 완료 체크
- 진행률 자동 반영

예시

[ ] 자료 조사 \
[ ] 발표 자료 제작 \
[x] 주제 선정

---

### 📝 메모 기능

각 Todo 항목마다 별도 메모 작성 가능

사용 방법

1. Todo 제목 더블 클릭
2. 메모 창 열기
3. 내용 작성
4. 자동 저장

---

### 📅 일정 관리

- 날짜 선택
- 시간 선택
- 마감 시간 설정
- 마감 초과 자동 감지

---

### 🚨 알림 기능

프로그램 실행 중 자동 알림 제공

- 30분 전
- 10분 전
- 1분 전

마감 초과 시 상태 자동 변경

- 진행 전 → 지연
- 진행 중 → 지연

---

### ⏳ 진행 상황 표시

각 Todo는 생성 시점과 마감 시점을 기준으로 진행 상태를 계산합니다.

표시 정보

- 남은 시간
- 진행 바
- 상태 태그

진행 바는 시간이 지날수록 감소하며,
마감이 가까워질수록 색상이 변화합니다.

---

### 🎯 우선순위 관리

- 높음 🔥
- 보통 ⭐
- 낮음 🌱

우선순위에 따라 카드 좌측 색상 바가 변경됩니다.

---

### 📂 카테고리 관리

- 학업
- 개인
- 팀플
- 업무

카테고리별 분류 가능

---

### 📑 자동 그룹화

마감일 기준 자동 정렬

- 초과
- 오늘
- 내일
- 모레
- 기타 날짜

그룹 접기 / 펼치기 지원

---

### ⏰ 집중 타이머

Pomodoro 스타일 집중 타이머

- 시간 설정
- 시작
- 일시정지
- 초기화

집중 시간 관리 가능

---

### 💾 자동 저장

프로그램 종료 시 자동 저장

저장 파일

```text
todo_data.json
```

프로그램 재실행 시 자동 불러오기

PyQt5 설치


프로그램 실행

```bash

```

## 저장 방식

프로그램 데이터는 JSON 형식으로 저장됩니다.

저장 항목

- 제목
- 생성 시간
- 마감 시간
- 우선순위
- 카테고리
- 상태
- 완료 여부
- 메모
- 체크리스트

자동 저장 시점

- Todo 추가
- Todo 수정
- Todo 삭제
- 완료 체크
- 프로그램 종료

저장 파일:

```text
todo_data.json
```
